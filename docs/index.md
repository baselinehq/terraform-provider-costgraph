# CostGraph provider

Manage CostGraph configuration in hosted or self-hosted deployments using an API key. Use the API URL of the deployment you want to manage.

## Configure authentication

Set `COSTGRAPH_API_KEY` to an API key from the deployment you want to manage.
The resource documentation lists the permissions that the key needs.
Creating tenants, connecting AWS, Google Cloud, or Azure accounts, and reserving
Kubernetes registrations require an active organization owner's user API key
explicitly granted `organization:manage`.
Existing keys do not receive it automatically. Normal data queries remain
tenant-bound. Installation tokens are not management credentials.

Virtual tags require a key bound to the target tenant with `virtual-tags:read`
for lookup or `virtual-tags:write` for management. Write permission includes
read access. `organization:manage` does not grant virtual-tag access or let a
bootstrap key manage another tenant's tags. Use a separate provider alias with
that tenant's key when your configuration also manages organization resources.

Keep the organization-management key in a bootstrap tenant. Reference each managed tenant from its child
integration resources so Terraform disconnects them before deactivating the tenant.
The default tenant and the tenant owning the active key cannot be deleted.

These management resources require the accompanying CostGraph backend APIs.
An older hosted or self-hosted deployment may not expose them yet.

For hosted CostGraph, the API URL defaults to `https://api.costgraph.ai`.
For a self-hosted deployment, set `COSTGRAPH_API_URL` to its API base URL.
Omit `/api/v1` and keep any reverse-proxy path prefix.

You can also set `api_key` and `api_url` in a provider block.
Explicit values take precedence over environment variables.
Keep keys in environment variables or sensitive input variables.

## Configure hosted CostGraph

The following example uses `COSTGRAPH_API_KEY` and the hosted API URL default.

```terraform
terraform {
  required_providers {
    costgraph = {
      source = "baselinehq/costgraph"
    }
  }
}

provider "costgraph" {}
```

## Configure self-hosted CostGraph

Set `COSTGRAPH_API_KEY` to a key from your self-hosted deployment. The following
example connects Terraform to that deployment's API.

```terraform
terraform {
  required_providers {
    costgraph = {
      source = "baselinehq/costgraph"
    }
  }
}

provider "costgraph" {
  api_url = "https://costgraph-api.internal.example.com"
}
```
